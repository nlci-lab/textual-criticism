# Images: one self-hosted CNTR page, links for the rest

Checked in Nov 2026: Vatican, CSNTM and CNTR's site text reserve rights; NT.VMR and the British Library forbid framing; Sinaiticus, Gallica and Cambridge licences are unconfirmed. CNTR, however, marks each of its page photographs as public domain in the United States under *Bridgeman v. Corel* (1999), noting that use may be restricted elsewhere.

So each profile may show one page photograph from CNTR, resized and self-hosted (`public/img/ms/`, under ~90 KB, lazy-loaded below the fold), with CNTR credited, the Bridgeman note, and a link to the original. For manuscripts held by the Vatican Library (B, 𝔓⁷⁵) we show no copy, out of courtesy to the Vatican's request for permission, and link to the image instead. Everything else is linked, not copied; CNTR's transcription view still opens in a modal frame.
